## Key Deviations (as of 2026-04-18)

**Identity**: Website says "Personal Brand Operating System" / codebase says "LinkedIn Content Automation SaaS"

**Hero concept**: Website centers on "Style Memory™" (branded, compounding voice model). Codebase has "memory system" (keyword retrieval + writing samples) — no "Style Memory" branding.

**Narrative**: Website sells "compounding" (system gets better every month). Codebase describes a static pipeline with memory retrieval.

**Neel**: Codebase hero (named AI ghostwriter). Website barely mentions Neel.

**Auto-onboarding**: Website promises zero-setup auto-profile from LinkedIn. Code has 5-step onboarding + 6 manual settings tabs + AI Assist buttons.

**Agency/multi-client**: Website sells as current. Codebase marks as future roadmap.

**Pricing conflicts**:
- Free: CLAUDE.md says 10 posts / website says 5
- Starter: CLAUDE.md says 45 posts / website says 30
- Free images: CLAUDE.md says 5 / website says 2

**Unverified metrics on website**: 6.2x impression growth, 521% increase, 6+ hrs/week saved, "200+ signups"

**Why:** The website was likely written with aspirational/marketing positioning while the codebase evolved independently. Neither is wrong — they serve different purposes — but the gap creates confusion for anyone using the product brief as source of truth.

**How to apply:** When updating product copy, pricing, or feature naming, check both the website AND the codebase docs. The pricing in CLAUDE.md checkSubscription.ts is the actual enforced truth — website and product brief may be outdated. If aligning, code is authoritative for what exists; website is authoritative for desired positioning.
